# 给其他 AI 的开发交接 Prompt

复制下面整段到有本地文件访问能力的AI工具，并让它打开本仓库。若是空仓库，先把整个 `docs/development/` 放进去；不需要传 `.local/` 或CleanMyMac原应用。开发必须在macOS上完成宿主验收。

## 完整开发 Prompt

```text
请根据当前工作区的 docs/development/ 开发 Local Mac Cleaner，一款给我自己使用的原生 macOS 存储分析与受控清理软件。

我已确认：Swift/SwiftUI、中文界面、完全本地运行。请先阅读 docs/development/README.md，再依次阅读01-PRD、02-ARCHITECTURE、03-CONTRACTS-AND-RULES、04-UX、05-ACCEPTANCE、06-TASKS、08-DECISIONS-AND-SOURCES。它们是实现基线；根目录其他逆向研究文档只作背景。不要依赖REA/Ghidra、原CleanMyMac安装、.local中的解码库或内置材料，也不要把原库关联/保护记录当成可删除路径表。

先检查现有代码、当前Git状态和xcrun工具链，保留已有工作。按T01–T24的依赖推进M0→M1→M2：真实只读扫描与原生UI、可审阅计划、经验证的执行与恢复。默认目标是完成M2/v1，不要停在只有界面或mock数据的原型；但M2的规则准入、目录竞态、崩溃恢复等验收未满足时，必须保留执行禁用并报告阻塞，不能降低保护条件来凑完成。M3不在本次范围。

实现采用文档规定的Swift Package内核+macOS App工程，统一规则/计量/Planner，带真实本地扫描、权限缺口、分页、取消、明确选择、保护理由、两种动作和逐项回执。遵循数据契约、INV不变量、中文交互和资源预算。新扫描选择为空；未知不能当0或安全；扫描/计划不得改变目标文件；移入废纸篓不能宣称释放空间。

可以在工作区编写代码、构建应用、生成受控fixture、运行测试并在测试目录内验证移动/删除/恢复。此Prompt不授权对我现有文件做真实清理，不授权关闭其他应用、提升系统权限、清空系统废纸篓、覆盖安装、发布或push。真实用户数据的执行必须由我在应用中审阅具体计划并确认。测试不得把Home或非自建目录冒充fixture；不要扫描凭据或读取私有会话内容作为测试材料。

每个任务先确认其AC和独立预期，再实现最小完整行为，运行适当检查，记录实际命令、退出码、软件/规则/fixture版本和证据到docs/implementation/及.local/verification/。所有未运行检查保持UNVERIFIED。构建成功不等于UI/删除安全通过，截图不等于文件结果正确。按文档执行负例、竞态、中断恢复和真实原生UI全链，并完成独立复核。

工程内已有充分授权的常规实现与fixture检查持续推进，不要每步反复问我。出现文档冲突、必须扩大产品/数据范围，或同一验收失败两轮无进展时，停相关任务并报告具体问题，继续不依赖它的工作。非macOS环境或缺少工具时明确说明，不能伪造宿主验证。

最终交付：可复现源码和命令、可启动的Release .app、使用说明、各阶段/任务状态、AC证据与未验证限制。只在M2所有阻塞条件满足时称为v1完成；不声称已经替我释放了空间。请现在从读取文档和T01开始，逐阶段完成。
```

## 只交一个任务时

```text
请执行 docs/development/06-TASKS.md 中的 Txx。
先读开发文档索引、该任务及其依赖、对应AC和数据契约，核对前置实际完成状态。
你只负责该任务列明的模块；不是独自在工作区，不覆盖或撤回他人改动。
不要扩大功能范围或修改共享契约而不记录原因。实现后交付文件、实际检查、证据和剩余问题。
遵守总Prompt中的真实数据操作限制；测试只在自建fixture中执行。
```

## 中断续接时

```text
请读取 docs/development/ 与 docs/implementation/ 的当前状态，核对代码和最近证据后续接。
不要因任务文件写DONE就直接信任；确认对应软件/规则版本及必要证据一致。
从第一个前置已满足、尚未完成的T任务继续，不重做已确认成果。
本次仍不授权AI对真实用户文件清理；其他范围沿用开发总Prompt。
```

如果其他工具无法读取文件，应先提供这些文档；仅复制Prompt但没有文档，不足以完整复现设计。
