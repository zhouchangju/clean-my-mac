# Local Mac Cleaner 开发文档包

版本：v0.1 · 2026-10-12。工作名称 **Local Mac Cleaner**，简称 LMC；名称可更换。本文档包是后续实现的基线，当前没有应用代码、已通过的产品测试或发布制品。

用户已确认：原生 macOS，Swift/SwiftUI，中文界面，完全本地运行。目标是帮助本人判断空间占用并选择性回收，不追求复刻 CleanMyMac 全部能力。

## 交付路线

- **M0：可运行的只读原生应用**。选范围、扫描、空间排行、进度/取消/权限缺口、规则解释；不是静态演示页面。
- **M1：清理计划预览**。明确选择、忽略、可回建性、动作差异、计划失效与预检；仍无真实删除。
- **M2：v1 受控清理**。在测试目录中验证完整执行/中断/恢复，形成可本机运行的 `.app`；真实文件由用户在应用中选择并确认。此阶段才可称为具有清理能力的 v1。
- **M3：后续扩展**。模型、完整卸载、重复文件等，明确不属于默认开发 Prompt 的完成范围。

执行器可在开发过程中实现并对测试目录验证；文档和开发 Prompt 都不授权 AI 对用户现有文件做真实删除。缺少 Mac、权限或工程工具时，缺失项标 `BLOCKED/UNVERIFIED`，不能把跨平台静态检查当作 macOS 运行通过。

## 便携交接

将整个 `docs/development/` 文件夹和 [07-AI-HANDOFF.md](07-AI-HANDOFF.md) 的 Prompt 给其他 AI 即可开始。若交接现有仓库，还应保留原研究 Markdown；**不需要**传送 `.local/`、解码数据库、内置派生材料、用户会话或完整 CleanMyMac 应用。

本包已包含自研行为要求。原始研究只用于追溯，不是运行依赖；实现不得调用 REA/Ghidra、依赖 CleanMyMac 安装或直接加载其专有规则库。
