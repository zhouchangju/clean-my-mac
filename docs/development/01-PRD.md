# PRD：Local Mac Cleaner

版本 v0.1，2026-10-12；状态：设计基线，未实现。决策来源见 [08](08-DECISIONS-AND-SOURCES.md)。

## 1. 用户、问题与目标

第一用户是本人，使用 Apple Silicon Mac，内置存储有限，同时使用开发和 AI 工具。当前痛点不是缺一个“清理”按钮，而是不容易判断空间属于什么、删除有什么影响、究竟能释放多少，以及出错后发生了什么。

目标体验：打开应用 → 选择目录或内置卷范围 → 找到主要占用 → 看到可重建候选及保护理由 → 明确选择 → 查看精确清理计划 → 确认执行 → 获得逐项结果和空间变化。

成功由真实行为证明，不承诺固定释放 GB 数。v1 至少支持两个经准入的真实缓存/开发产物规则，并完成一次**应用自身创建的测试目录**内扫描到执行的原生 UI 全流程。用户真实数据上的收益属于后续使用观察，不能由 fixture 推断。

## 3. 功能需求

| ID | 要求 | 验收 |
|---|---|---|
| FR-01 | 首次启动无自动扫描；用户选择范围。支持目录选择和内置卷概览，始终展示实际扫描根与排除项 | AC-01、AC-02 |
| FR-02 | 后台增量扫描；UI 保持响应；进度以已处理项/当前范围表示，未知总量不伪造百分比；可取消并查看部分结果 | AC-03、AC-04 |
| FR-03 | 空间树/排行按已知分配大小排序；显示逻辑大小、分配大小、估算可回收量及未知状态，树和列表共享数据 | AC-05、AC-06 |
| FR-04 | 每项说明命中规则、归属、影响、默认选择建议、被保护/跳过原因。扫描出的所有文件不等于候选 | AC-07、AC-08 |
| FR-05 | 缓存/派生产物采用独立维护规则。规则准入前只预览；全新扫描的选择集合为空，“推荐”不等于已经勾选 | AC-08、AC-09 |
| FR-06 | 支持逐项/分组选择与持久忽略；保护项不可选；分组勾选仅作用于当前展示且可操作的后代，明确数量 | AC-10 |
| FR-07 | 生成绑定规则版本、扫描和文件身份的计划。更改选择/规则/忽略/范围即作废；执行前检查变化 | AC-11、AC-12 |
| FR-08 | 动作区分“移入废纸篓”和“永久删除缓存”。普通大文件仅前者；永久动作仅限经过准入的规则叶子文件 | AC-13、AC-14 |
| FR-09 | 执行逐项校验，支持停止后续项；不自动重试不确定结果；重启后对账并显示待恢复项 | AC-15、AC-16、AC-17 |
| FR-10 | 结果报告逐项状态、失败原因、恢复位置及卷空间变化；移入废纸篓不标为释放；失败不是0字节成功 | AC-18 |
| FR-11 | 设置可管理忽略项、扫描并发、历史保留；默认不常驻、不联网、不发送完整路径；历史及索引占用有上限 | AC-19、AC-20 |
| FR-12 | 提供中文原生界面、键盘操作、无障碍标识、深浅色、完整最小窗口布局和可启动本地 `.app` | AC-21、AC-22 |

## 4. 产品约束

- 扫描范围内依然执行保护策略；选择了 Home 不代表允许删除 Home 中全部文件。
- 符号链接只作为链接条目识别，不遍历目标；跨卷挂载不进入同一扫描树。
- 没权限的目录显示覆盖缺口。完整磁盘访问由用户在系统设置操作，不主动更改系统权限；未授权也能使用可读范围。
- 用户会话、凭据、代码仓库、文档、模型、备份不能因为“很大/很旧/在隐藏目录”就变成自动清理项。
- v1 永久清理只处理经过计划枚举的普通叶子文件，不递归删除整个目录；新出现的后代不自动追加。目录组仅是展示/选择容器。
- 已在使用、所有权不确定、根目录/文件身份变化、云占位符、硬链接等无法明确安全处理的项拒绝永久操作。

## 5. 质量目标

这些是本项目提出的验收预算，不是从 CleanMyMac 测得的指标。基准：Apple Silicon、本机 APFS、固定 50,000 文件测试集，记录硬件/系统/构建与温冷缓存条件。

| 指标 | 初始验收目标 | 判定 |
|---|---|---|
| 扫描时交互 | 95% UI 主线程抽样忙段不超过100ms；取消点击有即时反馈 | AC-23，实测，不能凭动画判断 |
| 取消到不再调度新 I/O | 正常本地 fixture ≤2秒；不可中断系统调用单列说明 | AC-04 |
| 数据驻留 | 不把全树路径/SwiftUI行全部常驻内存；50k基准峰值RSS≤500MiB | AC-23 |
| 产品数据 | 索引软上限250MiB；收据摘要保留90天/最多1000次，敏感明细最长30天；待恢复事务绝不自动清理 | AC-19 |
| 发行包 | 自包含 Release `.app` ≤100MiB（不含系统框架），无REA/JDK/Python运行依赖 | AC-22 |

预算若不合理，应提交测量和修改决策；不能为了通过删掉保护检查。首版不承诺全盘扫描时间、准确独占回收量或所有 macOS 版本兼容。

## 6. 发布定义

- M0：真实扫描驱动UI、只读不改目标、M0 AC通过，标“只读预览版”。
- M1：计划与失效/预检通过，标“计划预览版”。
- M2：执行器安全探针、正常/负例/崩溃恢复、原生 UI fixture 全链与可启动制品均通过，才能标“v1”。
- 真实文件第一次使用由用户在应用中审阅并操作；不是开发 AI 的自动验收动作。未做真实删除可如实交付 fixture 验证的 v1，不宣称已替用户释放空间。

## 7. 非阻塞假设

默认 macOS 14+、Apple Silicon、个人本地分发；仅当前宿主实测，最低系统兼容需独立记录。工作名、本地 bundle ID、性能预算、工程目录可在不扩范围的前提调整并留下决策。若改成跨平台、商店发行、后台自动清理或完整替代 CleanMyMac，必须重新定范围。
