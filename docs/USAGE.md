# 使用文档

面向最终用户的功能说明。安装请先看 [安装文档](INSTALL.md)。

## 核心理念：先分析，再审阅

本工具**只读分析**。扫描不修改你的任何文件；所有"清理建议"都附带规则理由、
计量状态（已计量/部分/不可读）与审阅能力；真实的删除执行当前处于关闭状态
（详见 [安全模型](../README.md#安全模型)）。看到"不可读"或"未知"是特性而不是
故障——工具拒绝假装知道它看不到的东西。

## 存储分析

### 存储看板

启动后的首页。选择扫描范围（内置磁盘 / 主目录 / 下载 / 自选目录）点「快速扫描」。
看板呈现：卷容量条、分类汇总（缓存/开发/下载/媒体/文档/应用/其他）、洞察卡片
（大文件、规则候选、覆盖缺口）、顶层目录占用排行。点击卡片可跳转对应视图。

### 空间地图 v2

回答"空间到底被谁占了"的页面：

- **瓦片** = 当前目录的直接子项，面积按 log₂ 压缩权重（小目录也能看见），
  颜色区分目录/文件，悬停显示真实字节与占比。
- **点击目录瓦片即下钻**；顶部面包屑可跳回任意层级；←/→ 后退/前进。
- **树图 / 列表**切换：列表模式显示当前层明细表格。
- 「重新扫描」需要确认（会丢弃当前结果）。
- 图上数字是"去重计量"：硬链接只计一次，所以可能与 Finder 的表观大小不同。

### 文件浏览

同层目录的传统表格视图：搜索相对路径、按分配/逻辑大小或修改时间排序、分页、
每行右键"在 Finder 显示"、双击目录进入。选中行在右侧详情面板展示该条目的
规则决策（为什么是候选/保护/审阅）与能力（仅预览/可入废纸篓等）。

### 大文件 / 整理建议

- 大文件：全扫描范围内的大文件清单，按类型过滤（音频/图片/视频/文档/压缩包/
  安装包/**AI 模型** gguf/safetensors/onnx/mlmodel…）。
- 整理建议：只有规则明确识别的候选（如 Xcode DerivedData、npm 临时缓存、
  Codex 缓存、浏览器缓存等）才出现在这里，并给出"重建影响"说明。

### 重复文件

独立扫描器（与主扫描互不影响）：默认扫描主目录，可自选目录。

- 三段漏斗保证零假阳性：精确尺寸 → 头 64KB SHA-256 → 全量 SHA-256。
- 结果按"可浪费空间"降序分组；展开组查看所有路径，可在 Finder 中定位。
- 硬链接会组成"硬链接组"并标注（删除其一不释放空间）。
- 支持 JSON 导出与随时取消。当前**不提供删除按钮**（执行未开放）。

## AI 体检中心

侧栏「AI 体检中心」包含两个区块。

### AI Runtime 与 AI 空间分析

1. **检测**：进入页面自动检测本机 AI CLI（Codex CLI、OpenCode、Droid、
   Ollama、Claude Code），显示路径与版本；未检测到的如实标注。
2. **默认 Runtime**：下拉选择并持久化；也可在每次分析时临时选择。
3. **AI 空间分析**：需要先完成一次扫描。点击「运行分析」后，应用把
   **脱敏后的扫描摘要**（卷信息、分类汇总、条目导出，用户名与敏感段已打码）
   连同分析指令交给所选 Runtime 以**只读沙箱**执行（如
   `codex exec --sandbox read-only`），回答以 Markdown 呈现并可复制。

   > AI 输出**仅为建议**。本应用不会据此执行任何删除或修改；任何清理仍需
   > 走规则候选 → 计划预览的链路（当前执行关闭）。

### Guardian Skill 体检

- **磁盘体检**：调用 `mac-storage-guardian` 的只读审计，呈现卷容量、实际/表观
  占用、候选分类（迁移候选 / 待复查）与权限盲区，并生成建议列表。解析失败时
  原文兜底显示。审计只读，不迁移任何文件。
- **内存体检**：调用 `mac-memory-guardian` 检查内存压力，呈现判定与候选
  （闲置 Codex 进程：green/yellow + 原因 + 内存占用）。其安全协议被完整保留：
  - 压力正常 → 只报告，零动作；
  - **校准模式**（首次常见）：所有提案标注"演示（would do）"，除非你显式点
    「批准校准」——批准后本轮立即结束，不做任何清理；
  - green 候选的「终止（受控）」按钮每次只处理一个进程，执行前有确认框，
    动作后自动重新体检；
  - 全程 45 秒预算，超时如实报告已完成/已跳过项。

「性能监控」页与菜单栏波形图标提供 CPU/内存/启动盘概览与进程排行（独立工作流，

## lmc 命令行参考

```bash
# 扫描（结果写入本地索引，输出终端 JSON）
lmc scan --root ~/Downloads

# 由扫描结果构造清理计划（仅预览；无执行子命令）
lmc plan --scan <scanUUID> --selection <uuid1,uuid2> --action trash|purge

# 检查执行回执文件
lmc inspect-receipt <receipt.json>

# AI Runtime
lmc air list                    # 检测全部 runtime（JSON）
lmc air default codex           # 设置/读取默认 runtime
lmc air analyze --runtime codex --context-file ctx.json
```

约定：成功输出 JSON 到 stdout；错误输出到 stderr 并以退出码 2 结束。

## 数据与隐私

- 索引：`~/Library/Application Support/LocalMacCleaner/index.sqlite`
  （0700/0600、1 GiB 配额、另有 1 GiB 磁盘保留水位保护）。
- 完全本地：除你主动触发的 AI 分析（交给本地 AI CLI）外无任何网络行为。
- 导出（文件浏览页「导出本页」/重复页「导出 JSON」）默认脱敏。

## 常见问题

| 现象 | 说明与处理 |
|---|---|
| 目录显示"不可读" | macOS TCC 授权限制。为应用/终端开启"完全磁盘访问"后重扫；未授权部分会一直如实标注 |
| AI 分析报"未检测到"或命令错误 | 用 `lmc air list` 检查；确认对应 CLI 已安装且已登录（如 `codex login`）；版本升级导致参数漂移时错误信息中含可复制的完整命令 |
| 磁盘体检超时 | 全量主目录审计实测需 2–4 分钟，超过当前 60 秒预算会如实报告失败；等待后续版本支持范围注入 |
| 内存体检显示"校准模式" | Skill 协议的首次校准机制：全部提案仅演示；批准校准后从新体检开始 |
| 面积/大小与 Finder 不一致 | 本工具按"分配大小 + 硬链接去重"计量，Finder 显示表观（逻辑）大小；稀疏文件分配可为 0 |
| 想清理候选文件 | 当前版本执行关闭：请用「预览计划」查看，等待受控执行开放（见 [安全模型](../README.md#安全模型)） |
