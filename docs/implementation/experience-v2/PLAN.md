# 体验改进 v2（2026-10-13）

用户试用反馈：全盘扫描需要自己选择路径，文件结果难读，缺少优化建议与分析看板。目标是实际提升原生应用，不只交研究报告或静态设计。

## 依据与范围

MacPaw官方Space Lens指南默认选择主盘，结果提供占用分布、按大小排序的同层项目、视觉地图、下钻/面包屑和审阅动作；Smart Care按模块给结果卡片和Review入口。官方页面与本机实际页面观察分开记录。我们采用一键内置数据卷入口、空间分析看板、分类审阅/清理建议、明确覆盖缺口，不复制品牌资源，不虚构恶意软件/性能检测或精确可释放量。

v2可使用只读元数据计量受保护的应用/代码仓库；保护状态继承到后代，任何候选/选择/Planner能力仍被禁止。凭据、会话、云同步、未恢复事务依旧不深入；此修改服务于空间分析，不开放清理。ScanScope仍固定单卷身份；Data卷别名路径规范化仅用于规则判定，实际文件读写定位保持anchored真实路径。首次启动默认主盘但不自动扫描。

## 实现与验收

1. 默认内置存储、我的文件、下载、自选目录快捷入口；一击内置扫描，不开NSOpenPanel。
2. 看板用真实SQLite数据展示卷容量/可用、已扫描已知分配、分类、同层大目录、可审阅缓存/大文件/权限问题。未知与未覆盖清楚区分；无健康分或伪收益。
3. 空间地图与排行共用同层条目，目录下钻/面包屑/返回；禁止混合全树父子造成视觉重复计量。支持分配/逻辑/修改时间排序和筛选。
4. 建议页显示原因、用途、重建影响、能力，仅匹配准入规则才叫缓存候选；普通文件整理和保护计量分开。缓存未准入保持仅预览。
5. 原生窗口1000×680和1180×780，深浅色、空/扫描中/完成/取消/partial/错误与长路径。实际fixture验证新入口、数据/图联动、下钻、筛选、计划失效与执行Gate。
6. 制品为新的独立Release .app，构建/启动/截图/源码review与证据记录；不覆盖安装，不清理现有用户文件。

新功能不能复用旧制品验收；未运行测试UNVERIFIED。原M2执行/恢复阻塞继续保留，本轮不能靠研究竞品打开执行。
